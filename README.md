# 摩尔小镇

一个用 Godot 4 写的摩尔庄园风格小游戏。所有画面都由代码绘制，不依赖任何图片素材，打开即可运行；支持局域网多人联机和去好友家农场串门。

## 运行

用 Godot 4.7+ 打开 `project.godot`，按 F5。

## 玩法

| 地点 / 角色 | 玩法 |
| --- | --- |
| 开心农场 | 6 种作物（萝卜、草莓、玉米、南瓜、向日葵、西瓜），随玩家等级解锁；在右下角选种子（或按数字键 1~6），点空地播种；点作物浇水（20 秒内生长翻倍）；浇过水再点一下施肥（Lv2 解锁，生长 ×1.5、收获多 1 个）；作物成熟时偶尔会长成巨型作物（施过肥概率 ×3），收获多 3 个；成熟后收获；有害虫时点击抓虫 |
| 钓鱼湖 | 点击湖面钓鱼，鱼上钩后红色标记在绿色区域时按空格收杆；每个季节有一种限定鱼，偶尔还能钓到宝箱和漂流瓶；联机时和好友挨着一起钓鱼更容易钓到金鱼；夏天的夜里湖边和树林里还有萤火虫可以抓（攒够 10 只送萤火虫灯），春天草丛里藏着四叶草（找到当天是幸运日），秋天白天有落叶堆、冬天有雪堆可以翻；每条鱼有随机尺寸，图鉴里记录每种鱼的最大纪录 |
| 摩尔百货 | 找店长豆豆买种子、拉姆果、帽子，卖掉作物和鱼；作物收购价每天浮动，每天有热门收购和特价种子 ；「工具」页有更好的鱼竿、自动洒水器和温室 |
| 主线剧情 | 升到 2 级后开始「城堡的秘密」，跟着左上角的提示和箭头一步步揭开城堡的秘密，完成后获得专属的星星发卡 |
| 随机事件 | 夜里可能有流星雨（点击流星许愿得奖励）；白天可能有迷路的小拉姆（小地图上有问号，找到后带去乐乐那里） |
| NPC 作息 | 晚上 22 点后小镇居民会回家睡觉，早上 6 点醒来（店长通宵营业） |
| NPC 好感 | 每个 NPC 每天可以送一次礼物，送他们喜欢的东西好感涨得快，好感到 20 / 50 / 100 会收到回礼；每个 NPC 一年里有一天生日（对话标题能看到），当天送礼好感翻倍，前一天信箱会有提醒 |
| 小厨房 | 广场左边的灶台：用作物和鱼做 7 种菜，卖得更贵，也是拉姆和 NPC 最爱的礼物 |
| 留言板 | 广场右边的留言板可以贴留言，联机时所有人看到的是同一块板 |
| 城堡 | 点击城堡大门可以进入城堡大厅找摩尔国王接受每周挑战（奖励 300 豆和专属的金奖杯），或者玩「接果子」小游戏（每天前 3 次有奖励） |
| 我的小屋 | 小院左边的小房子，进门后可以睡觉（晚上 8 点后直接睡到第二天早上，作物照常生长）、在衣柜换帽子、看奖杯架 |
| 旅行商人 | 每周末白天在湖边摆摊：神秘种子袋、望远镜（专属家具）、便宜的肥料和拉姆果 |
| 扭蛋机 | 广场东边，50 摩尔豆扭一次：摩尔豆、种子、拉姆果、家具，还有扭蛋限定的帽子「兔耳朵」「小黄鸡」 |
| 信箱 | 小屋门口的信箱，小镇的朋友会寄信来（好感越高礼物越好），有新信时竖起红旗；每天早上还有一份「小镇日报」，总结昨天收获、钓鱼、做菜、帮忙和赚到的摩尔豆 |
| 我的小院 | 在商店「家具」页买家具（每个季节还有一件限定家具），背包里点「摆放」放进农场旁的小院；点击已摆好的家具可以移动或收起，好友串门时能看到 |
| 乐乐 | 在广场领取任务（收获、钓鱼、做菜、送货），完成后回来领摩尔豆 |
| 拉姆 | 跟着你飞的小宠物，饿了会飞不动，点击喂食、吃饱了点击摸摸它；亲密度升级后会帮你抓虫（Lv3）、找宝物（Lv4）、浇水（Lv5） ；可以在商店给它买蝴蝶结、小眼镜、小围巾；Lv2 起每天第一次在它吃饱时摸摸它，会邀请你玩捉迷藏（90 秒内找到躲在草丛里的它，+30 豆） |

一年有春夏秋冬四季（每季 7 天），景色会变化，冬天会下雪；作物在自己的季节长得更快。每 7 天一次钓鱼大赛、丰收节（第 7 天 / 第 3 天循环），广场会挂上彩旗；会随机下雨（自动浇灌农田）、刮风、清晨起雾，夜晚路灯和窗户会亮起。音效和背景音乐都是代码实时合成的（白天、夜晚、节日各有一首曲子，会自动切换），可在「设置」里调音量、界面大小或重置存档。

每天第一次进入可以签到领摩尔豆（连续 7 天奖励递增）；按 C 打开图鉴，查看收集进度和二十多个成就；已达成的成就可以设为称号，显示在名字下面（联机时大家都看得到）。

第一次进入时可以给小摩尔起名字、选毛色（之后在「设置」里修改）。接着会有 6 步新手引导（种菜、浇水、钓鱼、买种子、找乐乐、喂拉姆），左上角显示提示、地图上有橙色箭头指路，完成后有奖励，也可以随时跳过。

做各种事都会获得经验，升级（最高 10 级）会解锁新作物和新帽子。

键盘也能玩：WASD / 方向键走路，F 和身边的东西互动。右上角的小地图可以点击直接传送。鼠标滚轮、+ / - 键或触屏双指捏合可以缩放镜头（触屏点按就是点击）。

快捷键：回车 聊天，E 表情，F 互动，C 图鉴，M 小地图，B 背包，N 联机，H 帮助，F12 截图，Esc 关闭窗口。游戏每 30 秒自动保存，离线时作物也会生长。存档写入时会先写临时文件并保留上一份备份，存档意外损坏时会自动从备份恢复。

## 多人联机

1. 按 N 打开联机面板，一人点「创建房间」（默认端口 7777），把面板上显示的局域网 IP 告诉小伙伴。
2. 其他人打开联机面板，同一个局域网里的房间会自动出现在「附近的房间」里，点「加入」即可；也可以手动填入房主 IP 再点「加入房间」。首次创建房间时请在 Windows 防火墙弹窗中允许。
3. 天气和一天中的时刻以房主为准，大家看到的白天黑夜、下雨下雪都一样。
4. 联机后可以看到彼此走路、钓鱼、帽子和拉姆，可以聊天、点击其他玩家打招呼、送摩尔豆或送礼物（作物、鱼、种子、家具……）。和身边的好友同时做同一个表情就是「一起跳舞」，会有小奖励。

**串门**：点击其他玩家选「去TA家农场串门」。农场和小院会显示好友的实时农田和家具：浇水 +2、抓虫 +3 摩尔豆（每天最多领 20 次帮忙奖励），每块成熟的作物可以摘一个。点顶部「回家」返回。

同一台电脑测试联机时，用不同的存档档位启动两个窗口：

```bash
godot --path . -- --profile=1
godot --path . -- --profile=2
```

## 代码结构

```
scripts/
├── autoload/   自动加载的全局单例
│   ├── game_state.gd   游戏状态与规则：摩尔豆、背包、任务、时间、天气、存档……（按功能分段）
│   ├── net.gd          联机（ENet）：玩家名单、移动 / 聊天 / 送礼 / 串门同步、局域网发现
│   └── sfx.gd          代码合成的音效、背景音乐、雨声
├── data/       纯数据表（GameState 里有同名常量指向这里）
│   ├── items.gd        作物、鱼、帽子、家具、料理、拉姆饰品、鱼竿、旅行商人的货
│   ├── progress.gd     成就、新手引导、国王的每周挑战
│   └── story.gd        NPC 喜好、信件、主线剧情
├── world/      场景和地图上的东西
│   ├── main.gd         搭建场景、处理点击、昼夜、房间切换、远程玩家管理
│   ├── world.gd / prop.gd / rain.gd          地面、建筑装饰、下雨下雪起风起雾
│   ├── plot.gd / greenhouse.gd / sprinkler.gd 农田、温室、洒水器
│   ├── pond.gd / stove.gd / gacha.gd / board.gd / gate.gd   钓鱼湖、小厨房、扭蛋机、留言板、城堡大门
│   ├── interior.gd / castle_hall.gd / spot.gd 小屋室内、城堡大厅、室内可点的地方
│   └── furniture.gd / festival_deco.gd / tutorial_arrow.gd   小院家具、节日装饰、引导箭头
├── entities/   角色
│   ├── mole.gd         摩尔角色基类（绘制、走路、气泡、表情、帽子）
│   ├── player.gd / npc.gd / remote_mole.gd   玩家、NPC、其他联机玩家
│   └── lahm.gd / lost_lahm.gd                 拉姆、迷路的小拉姆
├── events/     随机事件和季节小玩法
│   └── events.gd / firefly.gd / leaf_pile.gd / clover.gd   流星雨、萤火虫、落叶堆 / 雪堆、四叶草
├── ui/         界面
│   ├── ui.gd           界面主体：状态栏、背包、对话、聊天、钓鱼、联机面板，并创建下面的模块
│   ├── ui_shop.gd / ui_progress.gd / ui_activities.gd / ui_profile.gd / ui_kitchen.gd / ui_mail.gd
│   └── minimap.gd / minigame.gd
└── util/draw_util.gd   画椭圆、圆环、文字、爱心的小工具
tests/          冒烟测试 smoke_test.tscn、浸泡测试 soak_test.tscn
```

新增作物：在 `scripts/data/items.gd` 的 `CROPS` 里加一行，再在 `scripts/world/plot.gd` 的 `_draw_ripe` 里画出成熟的样子。

## 说明

农场、背包和摩尔豆保存在各自电脑上，联机没有防作弊，适合和朋友在局域网里玩。

## 测试

`tests/smoke_test.tscn` 会启动真正的游戏场景，把捏脸、农场、天气、钓鱼、商店、拉姆、任务、等级、小院、NPC 好感、签到、传送、表情和存档读档挨个跑一遍，最后打印结果，失败时退出码为 1：

```bash
godot --headless --path . res://tests/smoke_test.tscn -- --profile=smoke
```

测试使用单独的 `smoke` 存档档位，结束后会自动删除，不影响正常存档。

`tests/soak_test.tscn` 是浸泡测试：机器人用 8 倍速随机玩 1 分钟（走路、互动、点对话、钓鱼、做菜、开关面板、换季、换天气、存读档），用来发现偶发的运行时错误：

```bash
godot --headless --path . res://tests/soak_test.tscn -- --profile=soak
```

## 打包分享（导出 Windows 版）

项目里已经带了 Windows 导出预设，导出后的 exe 不需要安装 Godot，可以直接发给小伙伴一起联机。

1. 第一次导出前，在 Godot 编辑器里点「编辑器 → 管理导出模板 → 下载并安装」（约 1 GB，只需一次）。
2. 在编辑器里点「项目 → 导出 → Windows Desktop → 导出项目」，或者用命令行：

```bash
godot --headless --path . --export-release "Windows Desktop" build/mole_town.exe
```

导出的文件在 `build/` 文件夹里（已加入 .gitignore，不会提交）。
