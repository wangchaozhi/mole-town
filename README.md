# 摩尔小镇

一个用 Godot 4 写的摩尔庄园风格小游戏。所有画面都由代码绘制，不依赖任何图片素材，打开即可运行；支持局域网多人联机和去好友家农场串门。

## 运行

用 Godot 4.7+ 打开 `project.godot`，按 F5。

## 玩法

| 地点 / 角色 | 玩法 |
| --- | --- |
| 开心农场 | 6 种作物（萝卜、草莓、玉米、南瓜、向日葵、西瓜），随玩家等级解锁；在右下角选种子，点空地播种；点作物浇水（20 秒内生长翻倍）；成熟后收获；有害虫时点击抓虫 |
| 钓鱼湖 | 点击湖面钓鱼，鱼上钩后红色标记在绿色区域时按空格收杆 |
| 摩尔百货 | 找店长豆豆买种子、拉姆果、帽子，卖掉作物和鱼；作物收购价每天浮动，每天有热门收购和特价种子 |
| NPC 作息 | 晚上 22 点后小镇居民会回家睡觉，早上 6 点醒来（店长通宵营业） |
| NPC 好感 | 每个 NPC 每天可以送一次礼物，送他们喜欢的东西好感涨得快，好感到 20 / 50 / 100 会收到回礼 |
| 小厨房 | 广场左边的灶台：用作物和鱼做 7 种菜，卖得更贵，也是拉姆和 NPC 最爱的礼物 |
| 留言板 | 广场右边的留言板可以贴留言，联机时所有人看到的是同一块板 |
| 城堡大门 | 点击城堡大门玩「接果子」小游戏，每天前 3 次有摩尔豆和经验奖励 |
| 我的小院 | 在商店「家具」页买家具，背包里点「摆放」放进农场旁的小院；点击已摆好的家具可以移动或收起，好友串门时能看到 |
| 乐乐 | 在广场领取任务，完成后回来领摩尔豆 |
| 拉姆 | 跟着你飞的小宠物，饿了会飞不动，点击喂食、吃饱了点击摸摸它；亲密度升级后会帮你抓虫（Lv3）、找宝物（Lv4）、浇水（Lv5） |

一年有春夏秋冬四季（每季 7 天），景色会变化，冬天会下雪；作物在自己的季节长得更快。每 7 天一次钓鱼大赛、丰收节（第 7 天 / 第 3 天循环），广场会挂上彩旗；会随机下雨（自动浇灌农田），夜晚路灯和窗户会亮起。音效和背景音乐都是代码实时合成的，可在「设置」里调音量或重置存档。

每天第一次进入可以签到领摩尔豆（连续 7 天奖励递增）；按 C 打开图鉴，查看收集进度和十几个成就。

第一次进入时可以给小摩尔起名字、选毛色（之后在「设置」里修改）。

做各种事都会获得经验，升级（最高 10 级）会解锁新作物和新帽子。

键盘也能玩：WASD / 方向键走路，F 和身边的东西互动。右上角的小地图可以点击直接传送。

快捷键：回车 聊天，E 表情，F 互动，C 图鉴，M 小地图，B 背包，N 联机，H 帮助，Esc 关闭窗口。游戏每 30 秒自动保存，离线时作物也会生长。

## 多人联机

1. 按 N 打开联机面板，一人点「创建房间」（默认端口 7777），把面板上显示的局域网 IP 告诉小伙伴。
2. 其他人填入房主 IP，点「加入房间」。首次创建房间时请在 Windows 防火墙弹窗中允许。
3. 联机后可以看到彼此走路、钓鱼、帽子和拉姆，可以聊天、点击其他玩家打招呼、送摩尔豆或送礼物（作物、鱼、种子、家具……）。

**串门**：点击其他玩家选「去TA家农场串门」。农场和小院会显示好友的实时农田和家具：浇水 +2、抓虫 +3 摩尔豆（每天最多领 20 次帮忙奖励），每块成熟的作物可以摘一个。点顶部「回家」返回。

同一台电脑测试联机时，用不同的存档档位启动两个窗口：

```bash
godot --path . -- --profile=1
godot --path . -- --profile=2
```

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `scripts/game_state.gd` | 自动加载：摩尔豆、背包、任务、时间、存档、界面主题 |
| `scripts/net.gd` | 自动加载：联机（ENet）、玩家名单、移动/聊天/送礼/串门同步 |
| `scripts/sfx.gd` | 自动加载：代码合成的音效、背景音乐、雨声 |
| `scripts/rain.gd` | 下雨画面效果 |
| `scripts/main.gd` | 搭建场景、处理点击、昼夜变化、远程玩家管理 |
| `scripts/ui.gd` | 界面主体：状态栏、背包、对话、聊天、钓鱼、联机面板、小地图，并创建下面几个界面模块 |
| `scripts/ui_shop.gd` | 摩尔百货界面 |
| `scripts/ui_progress.gd` | 图鉴、成就、每日签到 |
| `scripts/ui_activities.gd` | 送礼物、接果子小游戏、留言板 |
| `scripts/ui_profile.gd` | 设置、表情栏、捏脸 |
| `scripts/ui_kitchen.gd` / `stove.gd` | 烹饪界面、小厨房灶台 |
| `scripts/mole.gd` | 摩尔角色基类（绘制、走路、气泡、钓鱼姿势） |
| `scripts/player.gd` / `npc.gd` / `remote_mole.gd` | 玩家、NPC、其他联机玩家 |
| `scripts/plot.gd` | 农田（含串门时显示好友农田） |
| `scripts/furniture.gd` | 小院家具（绘制、移动、收起） |
| `scripts/minimap.gd` / `minigame.gd` / `gate.gd` / `board.gd` / `festival_deco.gd` | 小地图、接果子小游戏、城堡大门、留言板、节日装饰 |
| `scripts/lahm.gd` / `pond.gd` / `prop.gd` / `world.gd` | 拉姆、钓鱼湖、建筑装饰、地面 |

新增作物：在 `game_state.gd` 的 `CROPS` 里加一行，再在 `plot.gd` 的 `_draw_ripe` 里画出成熟的样子。

## 说明

农场、背包和摩尔豆保存在各自电脑上，联机没有防作弊，适合和朋友在局域网里玩。

## 测试

`tests/smoke_test.tscn` 会启动真正的游戏场景，把捏脸、农场、天气、钓鱼、商店、拉姆、任务、等级、小院、NPC 好感、签到、传送、表情和存档读档挨个跑一遍，最后打印结果，失败时退出码为 1：

```bash
godot --headless --path . res://tests/smoke_test.tscn -- --profile=smoke
```

测试使用单独的 `smoke` 存档档位，结束后会自动删除，不影响正常存档。

## 打包分享（导出 Windows 版）

项目里已经带了 Windows 导出预设，导出后的 exe 不需要安装 Godot，可以直接发给小伙伴一起联机。

1. 第一次导出前，在 Godot 编辑器里点「编辑器 → 管理导出模板 → 下载并安装」（约 1 GB，只需一次）。
2. 在编辑器里点「项目 → 导出 → Windows Desktop → 导出项目」，或者用命令行：

```bash
godot --headless --path . --export-release "Windows Desktop" build/mole_town.exe
```

导出的文件在 `build/` 文件夹里（已加入 .gitignore，不会提交）。
